# Portfolio — guide agents

Site vitrine statique (HTML/CSS), déployé sur GitHub Pages.

## Layout

```
portfolio/
├── index.html
├── styles.css
└── README.md
```

## Preview local

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Ou via **Œil** → projet Portfolio → Preview :8080.

## Déploiement

Push sur `main` → GitHub Pages (repo `CloudDown/portfolio`).

Les coordonnées dans `index.html` sont **publiques** (vitrine volontaire).
